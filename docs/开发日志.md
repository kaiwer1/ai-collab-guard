## v2 · 2026-10-17 · workbuddy-step-5-preview

- 接手 DSH 的 v1 原型，新增「口径文件」巡检与变更检测：
  - `watch=version`：版本变更 = 口径版本事件；内容变而版本不变 = 静默改口径（告警）；
  - `watch=content`：内容变更 = 记录级；`watch=exists`：只盯存在性。
- 输出：干净时一行；有事件逐条列出（⚠ 告警 / · 记录）；`--json` / `--full` / `--registry`。
- 四场景自测通过：基线 / 无变更 / 静默改口径告警 / 正规升版本。
